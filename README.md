PACE Personal Finance Tracker

Tagline: Know your money. Keep your pace.

PACE is a premium, beautifully designed personal finance web application built entirely with vanilla web technologies. Moving beyond a standard expense CRUD app, PACE's core signature feature is its Financial Mood System—the entire user interface smoothly transitions its visual mood based on a real-time evaluation of your financial health.

🌟 Key Features

Dynamic Mood UI: The interface shifts through 6 visual states (Peaceful, Healthy, Caution, Warning, Critical, Overdrawn) using dynamic CSS variables depending on your "PACE Score".

Safe-To-Spend Engine: Intelligently calculates exactly how much you can safely spend today based on your income, fixed commitments, and days left in the month.

Interactive Calendar: A visual monthly calendar showing daily spending intensity and easy access to day-by-day transaction logs.

Fixed Commitments & Budgets: Separate tracking for recurring monthly bills and category-specific spending limits with visual progress bars.

Smart Analytics & Insights: Auto-generated financial insights, savings rate calculations, and CSS-based dynamic charts to track where your money goes.

100% Local & Private: All data is persisted entirely in your browser's localStorage. No accounts, no backend, no data sharing. Includes JSON Export/Import capabilities.

Responsive Design: A fully responsive, modern fintech aesthetic optimized for desktop, tablet, and mobile viewing.

🛠️ Technology Stack

PACE is built adhering strictly to a zero-dependency philosophy:

HTML5: Semantic and accessible structure.

CSS3: Advanced theming using CSS Custom Properties (variables) and modern CSS Grid/Flexbox layouts.

Vanilla JavaScript (ES6+): Complete logic engine, DOM manipulation, and local storage management in a single file.

No React, No Tailwind, No Build Tools, No Backend.

🚀 How to Run

Because PACE is completely zero-dependency and client-side, running it requires no setup:

Download or clone the repository.

Open index.html directly in any modern web browser (Chrome, Firefox, Safari, Edge).

(Optional) Go to Settings and click Load Demo Data to populate the app with sample data to see the features in action.

🎨 Design Philosophy

PACE utilizes a calm, premium, Apple-inspired fintech aesthetic. It relies on generous whitespace, the clean Inter typography family, soft shadows, and subtle micro-interactions to create a professional experience without the clutter of traditional dashboard layouts.
